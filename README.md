# Plant Doctor AI

## Explainable Plant Disease Detection Using GAN-Based Augmentation and Lightweight Deep Learning

Final-year AI/ML project.

## Tier 1 scope
- 8 PlantVillage classes
- RGB image classification
- EfficientNet-B0 baseline
- Proposed lightweight CNN with attention
- GAN-based augmentation
- Grad-CAM explainability
- Segmentation-based severity estimation
- Streamlit deployment

> Experimental metrics must only be reported after measurement. Unmeasured values use `[RESULT TO BE MEASURED]`.

## Setup
1. Create and activate a Python virtual environment.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Verify the environment:
   `python config.py`
